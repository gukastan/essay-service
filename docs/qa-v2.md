## 작성 후 기준 미충족 결과 변경 — 2026-10-21

기존에는 수정 한도 도달 시 `QUALITY_CHECK_FAILED`/`LENGTH_VALIDATION_FAILED` 422로 초안을 숨겼다. 이제 `review_needed` 200에 마지막 초안·실패 기준·사유·수정 안내를 포함한다. 작성 후 검토 모델이 필수 정보 부족을 지적한 경우에도 이미 생성한 초안을 표시한다. 작성 전 필수 경험 부족은 `needs_input`(초안 없음), 제공자/시간/형식 문제는 `error`로 남는다. 평가 기준이나 수정 한도는 완화하지 않았다.

Python 495건 통과·유료 검사 8건 기본 제외, JavaScript 13건 통과, Ruff·포맷·basedpyright 0오류를 확인했다. 800자 초안이 수정 한도에 도달해도 본문과 분량 지적을 함께 반환하는 회귀 테스트를 포함한다. 실제 Chrome에서 통제 모델을 연결한 전체 경로의 모바일/데스크톱·밝은/어두운 화면 네 조합을 확인했으며 모두 이번 초안과 미충족 알림을 표시했다. [입력·결과·화면 증거](qa-evidence/assignment/browser/review-needed-verification.md). 유료 모델 5개 샘플과 작성자 사실성 승인은 여전히 ESSAY-17 범위다. 아래 ESSAY-16 이전 수치와 422 화면은 당시 기준의 역사적 QA 기록이다.

## ESSAY-14 그래프·API 통합 검증 — 2026-10-21

`essay_graph.py`가 조사·분석 병렬 수집, D/E/F, G의 종료·수정 경로를 연결한다. 통제 모델 출력으로 정상 ready4회, D/I 수정·전체 재평가6회, 정보 부족/품질 실패, 분석 보완 시 조사 취소와 작성 차단을 확인했다. 한 통합 사례는 실제 stdio MCP와 사용자 제공 공고의 출처 검증을 거쳤으며 외부 OpenAI 유료 호출은 없었다. 실제 Uvicorn HTTP에서는 health200(`pipelineAvailable:true`, MCP 연결)과 잘못된 POST400을 확인했다.

## 화면과 오류·예외 증거

실제 Vue에서 입력→생성→근거 확인→원문 비교→편집→복사를 확인한다. 보완/오류 후 입력 유지, 편집 이후 생성 당시 검토 배지, 모바일 화면도 캡처한다.

키 누락·MCP 단절·모델/검색 timeout·품질 실패는 통제된 오류 주입으로 재현할 수 있다. 이 경우 주입 방법과 실제로 통과한 계층을 표시한다. 모의 모델 응답이 실제 생성 결과로 표시되거나 장애가 실서비스에서 자연 발생한 것처럼 보고되지 않도록 한다. 비밀·개인정보가 포함되지 않은 시험자료를 사용한다.
