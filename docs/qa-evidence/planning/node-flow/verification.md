## 반영한 계약

A~J 열 단계와 G의 다섯 분기를 정의했다. D/E 구성 재작성과 I 부분 수정은 같은 수정1회를 공유하고 수정 뒤 전체 F를 재실행한다. 최신 초안/계획 버전의 모든 필수 기준을 통과해야 H로 간다. J는 필수 정보 부족200과 정보 충분·품질 미충족422를 구분한다. 운영 오류/timeout은 별도로 종료한다.

네 모델 역할·정상4회/최대6회·기존 시간/토큰 상한을 유지한다. 초기 D는 추가 모델 없는 계획 조립 코드로 정의했다. 경험 순위·문단 전개·세부 프롬프트·평가 점수/가중치는 후속 설계다. 필수 사실성·근거·문항·직무·분량 검사는 첫 구현부터 필요하다.
