# ESSAY-17 사용자 Chrome 실제 모델 화면 중간 확인

- 시각: 2026-10-21 01:34 UTC. 사용자 Chrome의 `http://127.0.0.1:8600/` 탭을 사용했다. Vue 화면, 로컬 프록시, FastAPI, 실제 모델·MCP 설정을 연결한 실행이다.
- 기존 입력: 가상회사 새봄 / 서비스 기획 / 원본 `normal-collaboration` 문항·경험. **공고 본문 칸에도 자기소개서 문항이 반복 입력돼 있었다.** `초안 만들기`를 다시 누르자 “기업을 식별할 자료가 필요합니다”, `기업·공고 본문` 보완 질문이 표시됐다. 입력은 유지됐다.
- 진단 입력: 같은 원본 경험·문항을 유지하고 공고 본문만 `가상회사 새봄`, `서비스 기획 채용 공고 (테스트용 가상 공고)`, `서비스 기획 요건: 팀원과 협업하여 사용자 요구를 정리하고 화면 흐름을 개선한 경험.`으로 교체했다. 이 문구는 **실제 채용 공고가 아닌 시험자료**다. 이번에는 보완 요청 대신 “생성을 완료하지 못했습니다”가 표시됐다. [화면](essay17-chrome-synthetic-posting-error.png). 화면은 오류 세부 코드를 보여주지 않으므로 원인을 단정하지 않는다.
- 별도 브라우저 탭에서 `http://127.0.0.1:8001/health`는 `status:ok`, `modelConfigured:true`, `mcpConnected:true`, `pipelineAvailable:true`였다. 설정 누락이나 MCP 시작 실패 상태는 관측되지 않았다.
- 첫 결과는 자료가 부족할 때의 정상 보완 흐름이다. 두 번째 결과는 실제 작성 경로 실패이며, 같은 가상 공고의 [Python 실제 모델 중간 기록](../live/verification.md)에 근거 검증 실패와 작성 timeout이 별도로 있다. 이번 Chrome 결과의 정확한 서버 코드와 ready·편집·복사는 아직 확인하지 않았다.
