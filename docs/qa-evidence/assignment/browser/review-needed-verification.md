# 작성 후 기준 미충족 결과 검증 — 2026-10-21

## 범위와 실제 결과

사용자 결정에 맞춰 작성 후 `검증 및 평가`가 기준을 충족하지 못해도 마지막 초안과 지적을 `review_needed` HTTP 200으로 반환한다. 작성 전 필수 경험 부족은 `needs_input`(초안 없음), 운영 오류는 `error`로 구분한다. 평가 기준 7개와 D/I 공통 수정 1회는 유지했다.

| 시험 입력·조건 | 실제 결과 |
| --- | --- |
| 모든 기준 통과 | `ready` 200, 검토 통과 초안 |
| 계획/주장 문제 → 재계획 1회 → 여전히 실패 | `review_needed` 200, 마지막 초안·미충족 기준·사유·수정 지시, 세 번째 작성 없음 |
| 문장 문제 → 부분 수정 1회 → 계획 문제 발생 | `review_needed` 200, 전체 재평가 결과와 마지막 초안 |
| 초안 작성 후 필수 정보 부족으로 평가 | `review_needed` 200, 생성한 초안·필요 정보 표시 |
| 작성 전 필수 개인 경험 부족 | `needs_input` 200, 초안 없음 |
| 모델/시간 초과 등 운영 오류 | 오류 응답 유지, 미검토 초안을 통과/검토 결과로 포장하지 않음 |

Python 전체 회귀는 **495건 통과, 유료 모델 검사 8건 기본 제외**였다. 800자 초안이 수정 한도에 도달해도 본문과 분량 지적이 함께 반환되는 회귀 테스트를 추가했다. JavaScript 계약 검사 13건, Ruff 전체 검사, basedpyright 0오류, 변경 Python 파일 포맷 검사도 통과했다. 실제 Chrome은 통제 모델·조사 자료를 연결한 Vue→프록시→FastAPI→LangGraph 경로에서 `ready` 뒤 사용자 편집을 만들고 `review_needed`를 다시 요청했다. 이전 편집 내용 대신 **이번 900자 초안**과 문항 충족 지적이 표시됐다. 이어서 작성 후 정보 부족 평가에서도 초안과 필요한 경험 정보가 함께 표시됐다. 브라우저 예외와 가로 넘침은 관측되지 않았다.
