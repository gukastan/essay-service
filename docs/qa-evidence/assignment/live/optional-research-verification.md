# 선택 공고·공식 자료 없이 작성하는 흐름 검증

- 날짜: 2026-10-21
- 대상: assignment Python LangGraph 및 Vue 결과 표시
- 정책: 기업·직무·문항·경험은 작성 기준이다. 공고 URL/본문과 공식 자료는 선택적인 보강 근거다. 초안에서 사용한 사실의 근거는 계속 검증한다.

## 변경과 관찰

조사 노드는 신뢰할 외부 자료가 없는 가상 기업이라도 빈 조사 결과를 반환한다. 분석·계획·작성·검토는 확인된 공고 요건이 없다는 이유로 보완 요청을 만들지 않는다. 입력 직무와 다른 선택 공고의 요건은 사용하지 않는다. 이 경우 Vue 결과에 공고 요건을 반영하지 않았음을 표시한다. 개인 경험의 필수 정보가 부족할 때는 보완을 요청하며, 초안의 사실성·문항·직무 연결·분량 검사는 유지한다.

첫 실제 실행은 가상회사 새봄·서비스 기획·공고 없음으로 분석/작성/검토에 도달했지만 초안 길이 기준을 통과하지 못했다. [첫 실행 기록](original-normal-collaboration-20261021T044914458182Z.json). 고정된 경험 문장과 문단 구분자의 길이를 계산해 작성 모델에 남은 분량을 명시한 뒤 같은 입력으로 재실행했다.

[재실행 기록](original-normal-collaboration-20261021T045032074919Z.json)은 실제 OpenAI 모델과 실제 stdio MCP 경로를 사용했다. 결과는 `ready`, 824자, 모델 3회, 수정 0회, 공식 출처 0개, 공고 요건 0개, 개인 경험 근거 6개, 직무 연결 이유 1개였다. 검토 모델은 통과를 반환했고 개인 과거 사실 문장은 제공된 경험에서 선택됐다. 전체 5개 샘플의 품질·작성자 사실성 승인은 별개로 남아 있다.

통제된 통합 시험에서 가상회사·공고 없음과 입력 직무에 맞지 않는 선택 공고 모두 작성 완료를 확인했다. 후자는 실제 stdio MCP와 출처 검증기를 거쳤으며, 부적합 공고의 직무 요건은 결과에 포함되지 않았다. 최종 전체 회귀는 Python 495개 통과·유료 실행 8개 기본 제외, JavaScript 13개 통과였다. Ruff 검사/포맷과 프로젝트 설정 범위의 basedpyright는 오류 0개였다.
