# 결정: 제공 프로젝트를 기반으로 자기소개서 서비스 전환

- 날짜: 2026-10-20
- 상태: 사용자 승인, 문서·백로그 반영. 결정 당시 구현은 미착수였으며 이후 ESSAY-18 원본 실행과 ESSAY-19 공통 기반을 완료했다. 업무 기능은 후속 구현이다.
- 이전 결정: [LangGraph JS 기반 v2와 ESSAY-9 기록](langgraph-v2.md)
- 현재 명세: [전환 계획](../ASSIGNMENT_MIGRATION.md), [기술 설계](../TECH_DESIGN_V2.md)

## 근거

추가 과제 안내는 원본 프로젝트 실행을 먼저 수행하고 기존 LangGraph·MCP·LLM·Vue·FastAPI를 활용해 새 로직과 데이터를 구현하도록 한다. 제출물은 전체 소스, README, 변경 파일/기능 설명, 실행 화면, 기능별 실제 결과, 오류·예외 결과다. 사용자는 기존 작업을 보존하면서 이 방향으로 문서와 Jira를 갱신하도록 승인했다.

## 결정

제공된 소스를 저장소의 별도 assignment/에 가져와 실제 출발점으로 사용한다. Vue/FastAPI/MCP/Python LangGraph 구조를 유지하고 장애 진단 노드를 기업·직무 조사/경험·문항 분석/작성/검토로 바꾼다. 기존 Next.js v1·TypeScript ESSAY-9는 보존본이다.

기존 프롬프트·사실성 규칙·계약·예산·시험자료는 이식 자산이다. TypeScript 코드를 그대로 실행하는 것이 아니므로 Python 호환성·전체 흐름·실제 품질을 새로 검증한다. MCP를 제외하던 범위와 Next.js 안에 v2 API/기능 설정을 추가하던 계획은 대체한다.

MCP 조사 도구는 현재 OpenAI 키의 Responses 내장 검색을 1회 호출한다. 서버의 요청별 예산에서 모델1/내장용량2를 전송 전에 예약해 총4/최대6회 계약을 유지한다. MCP를 추가했다는 이유로 별도 검색 모델을 더 호출하거나 내부 검색어/페이지를 통제한다고 주장하지 않는다.

원본 대화 DB·GET 쿼리 전송·전체 프롬프트 노출·교육용 강제 통과·의도적 재시도는 단건 자기소개서 서비스 목적에 맞춰 제외한다. 원본 실행 증거와 변경 이유는 제출 자료에 남긴다.

## 결과와 상태

ESSAY-8은 전환 에픽으로 갱신하고 ESSAY-10~17의 구현 경로·완료 기준을 변경한다. ESSAY-18 원본 실행, ESSAY-19 Python 기반 이식, ESSAY-20 제출 자료를 추가한다. ESSAY-1~7·9 완료는 유지하고 새 작업은 할 일로 둔다. 이번 문서 갱신으로 원본 실행·이식·QA가 완료된 것은 아니다.
