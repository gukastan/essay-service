# 경험에 근거한 작성 방식

날짜: 2026-10-19. 적용 범위: ESSAY-4, ESSAY-7. 제공자와 모델은 OpenAI `gpt-5.6-terra`를 유지한다.

## 관찰한 문제

초기 실제 모델 출력은 없는 인원 합계, 구체적 발언, 체크리스트 항목과 후속 행동을 추가했다. 금지 지시를 세분화한 수정본에서는 정상 경험까지 보완 요청으로 돌리는 회귀가 생겼다. 작성 구조를 보강한 뒤에도 사건 사이의 시점과 과거의 배움을 추정하는 문제가 남았다.

분량 실패를 확인하기 위한 별도 진단에서는 실제 초안 736자가 재작성 후 749자에 그쳤다. 재작성에 실제 길이와 900자까지 필요한 증감량을 서버 지시로 전달하도록 바꿨다. 이는 출력 문자열을 자르거나 채우는 기능이 아니며, 기존의 최종 길이 검사와 최대 두 번 호출 규칙을 유지한다.

추론 설정만 `none`에서 `low`로 바꾼 run-6에서도 사실성 오류가 재현됐다. 따라서 추론 설정 변경 자체가 해결 원인이라고 주장하지 않는다. [공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-5.6-terra)에서 `low` 지원을 확인했으며, 이후 작성 방식 비교에서는 이 설정을 유지했다.

## 적용한 방식

과거 사실 문단은 경험 입력에서 관련된 완전한 문장을 선택해 원문과 순서를 보존하도록 지시한다. 새로 작성하는 내용은 별도 문단의 현재 해석과 짧은 미래 적용 계획으로 한정한다. 현재 관점이라는 표현을 붙여 원문에 없는 과거 효과나 내면 변화를 단정하는 것도 금지한다. 재작성에서도 선택한 사실 문장의 표현을 바꾸지 않고 문장 선택과 해석의 분량을 조정하도록 한다.

같은 5개 샘플의 run-7 결과에서 초기 구체적 사실 추가와 중간 수정본의 시점·후속 행동 추가를 찾지 못했다. 초안은 844·835·963·912자이며 정보 부족 사례는 보완 안내였다. 최종 전체 테스트 76개, lint, typecheck, production build가 통과했다. 원문·판정·실패 이력은 `docs/qa-evidence/live-model-revalidation/`에 보존한다.

## 선택의 한계

과거 문장을 자유롭게 다듬는 정도가 줄어들며 입력 문체가 더 많이 남는다. 짧은 경험에서는 해석과 다짐의 비중이 커질 수 있어 문장 완성도도 별도 검토해야 한다. 이번 고정 샘플은 완전한 한국어 문장으로 작성됐으며 모든 자유 형식 입력이나 반복 생성 품질을 검증한 것은 아니다.

이 방식은 모델에 주는 작성 지시이며, 출력의 모든 사실을 프로그램이 증명하는 검증기는 아니다. 실제 작성자의 최종 검토를 대체하지 않는다. `low` 설정의 일반적인 비용·지연 개선 효과도 측정하지 않았다. API 형식, 회당 30초, 요청당 최대 두 번, SDK 재시도 0, `store: false`는 유지한다.
